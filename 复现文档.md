# FastWAM + VLM-CoT 单任务评测复现文档

## 1. 环境准备

```bash
conda activate FastWAM
```

确保项目根目录为 `/path/to/FastWAM`，以下所有相对路径均基于项目根目录。

## 2. 预训练权重依赖

评测前需确保以下基础权重已就位（这些不在 HuggingFace 上传范围内，属于项目基础依赖）：


| 文件              | 路径                                                                 | 说明                        |
| --------------- | ------------------------------------------------------------------ | ------------------------- |
| Wan2.2-TI2V-5B  | `checkpoints/Wan-AI/`                                              | 视频生成骨干网络                  |
| Wan2.1-T2V-1.3B | `checkpoints/Wan-AI/`                                              | Tokenizer                 |
| ActionDiT       | `checkpoints/ActionDiT_linear_interp_Wan22_alphascale_1024hdim.pt` | Action DiT 预训练权重          |
| fastwam_release | `checkpoints/fastwam_release/robotwin_uncond_3cam_384.pt`          | FastWAM Pretrain 阶段权重     |
| CoT DiT         | `checkpoints/cot_dit_from_motus.pt`                                | CoT DiT 预训练权重（从 Motus 转换） |
| Qwen3-VL-2B     | `checkpoints/Qwen3-VL-2B/`                                         | VLM 在线特征提取模型              |
| dataset_stats   | `data/robotwin2.0/dataset_stats.json`                              | 数据集归一化统计量                 |


## 3. 从 HuggingFace 下载单任务微调权重

模型权重托管在 `Himmdy/FastWAM_VLMCoT` 仓库，按任务名组织：

```bash
# 安装 huggingface_hub（如已安装可跳过）
# pip install huggingface_hub

# 下载 turn_switch 任务权重
huggingface-cli download Himmdy/FastWAM_VLMCoT \
  turn_switch/step_002120.pt \
  --local-dir ./downloaded_weights

# 下载 place_can_basket 任务权重
huggingface-cli download Himmdy/FastWAM_VLMCoT \
  place_can_basket/step_000500.pt \
  --local-dir ./downloaded_weights
```

下载后文件结构如下：

```
downloaded_weights/
├── turn_switch/
│   └── step_002120.pt
└── place_can_basket/
    └── step_000500.pt
```

## 4. 单任务评测

### 4.1 评测脚本说明

评测入口为 `experiments/robotwin/eval_robotwin_single.py`，基于 Hydra 配置系统，使用 `configs/sim_robotwin.yaml` 作为基础配置。

核心参数：

- `ckpt`: 模型权重路径（必须）
- `EVALUATION.task_name`: 要评测的任务名（必须）
- `EVALUATION.replan_steps`: 重规划步数（默认 24）
- `EVALUATION.num_inference_steps`: 推理步数（默认 10）
- `EVALUATION.eval_num_episodes`: 评测 episode 数（默认 100）
- `gpu_id`: 使用的 GPU 编号（默认 0）

### 4.2 评测 turn_switch 任务

```bash
python experiments/robotwin/eval_robotwin_single.py \
  ckpt=./downloaded_weights/turn_switch/step_002120.pt \
  EVALUATION.task_name=turn_switch \
  EVALUATION.task_config=demo_randomized \
  EVALUATION.eval_num_episodes=100 \
  EVALUATION.replan_steps=24 \
  EVALUATION.num_inference_steps=10 \
  EVALUATION.dataset_stats_path=./data/robotwin2.0/dataset_stats.json \
  model.training.video_dit_mode=lora32 \
  model.training.action_dit_mode=lora32 \
  gpu_id=0
```

### 4.3 评测 place_can_basket 任务

```bash
python experiments/robotwin/eval_robotwin_single.py \
  ckpt=./downloaded_weights/place_can_basket/step_000500.pt \
  EVALUATION.task_name=place_can_basket \
  EVALUATION.task_config=demo_randomized \
  EVALUATION.eval_num_episodes=100 \
  EVALUATION.replan_steps=24 \
  EVALUATION.num_inference_steps=10 \
  EVALUATION.dataset_stats_path=./data/robotwin2.0/dataset_stats.json \
  model.training.video_dit_mode=lora32 \
  model.training.action_dit_mode=lora32 \
  gpu_id=0
```

### 4.4 评测结果

评测日志保存在 `evaluate_results/robotwin/<ckpt_tag>/<timestamp>/` 目录下。

## 5. 训练复现（可选）

如需从头训练单任务 CoT 微调模型：

```bash
bash scripts/train_zero1.sh 8 \
  task=robotwin_cot_3cam_384_1e-4 \
  model.training.video_dit_mode=lora32 \
  model.training.action_dit_mode=lora32 \
  data.train.task_names='[turn_switch]'
```

关键训练配置（对应 `configs/task/robotwin_cot_3cam_384_1e-4.yaml`）：

- 初始化模式: `fastwam`（从 Pretrain 阶段加载）
- Video DiT: LoRA rank=32
- Action DiT: LoRA rank=32
- 学习率: 1e-4
- Batch size: 16
- 优化器权重衰减: 1e-2
- 混合精度: bf16
